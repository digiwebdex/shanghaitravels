# V4 Responsive Guide

| Breakpoint | Width | Behavior |
|---|---|---|
| Mobile | < 640px | 1-col cards; stacked hero CTA; hamburger nav; partners scroll |
| Tablet | 640–1023px | 2-col destinations/blog/services; package carousel 1.2 peek |
| Desktop | ≥ 1024px | 4-col destinations; 3–4 package peek; full nav; hotline visible |

## Section rules

- Hero min-height `min(92vh, 820px)` desktop; `70vh` mobile  
- Service pills: 2×2 mobile, 4×1 desktop  
- Stats: 2×2 mobile, 4×1 desktop  
- Footer: 1-col → 2-col → 4–5-col  

## Touch

- Carousel arrows + swipe (Embla)  
- Tap targets ≥ 44px  
- Sticky header height compact on mobile
